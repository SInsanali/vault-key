# Changelog

## 0.9.0 - 2026-11-10

The first public version.

- Edit a character: level, money, Eridium, Seraph crystals, Torgue tokens, backpack and bank size, ammo upgrades, weapon slots.
- Duplicate an item, set one item's level, and move items between the backpack and the bank.
- Item names, cards and pictures, read from your own copy of the game.
- Every save is backed up first and can be restored. Characters are locked until you unlock them, and nothing is saved while the game is running.
- Open a save file from anywhere, and export a character to a file.
- An installer with a Start menu entry and an uninstaller, and a portable zip.

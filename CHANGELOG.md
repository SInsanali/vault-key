# Changelog

## Unreleased

- Shields, grenade mods and class mods are drawn in their own colours. Before, most came out washed-out white or grey, and some had a false purple tint or glitter.
- Relics glow in the colour of their kind (Tenacity green, Vitality red, Elemental purple, and so on) instead of plain gold.
- DLC weapons, shields, grenade mods, relics and class mods have pictures, Gaige's and Krieg's class mods among them.
- Fine patterns, such as the carbon weave on rarer shields and grenades, no longer turn to glitter in small pictures.
- Equipped gear is never saved above what the character can use (their level, plus Overpower at level 80). The game would take it off when it loads, so your equipped guns would end up in the backpack.
- A save that is gone or can't be read can be brought back from its backups: Settings, "Missing or damaged saves…", or click the damaged file in the list. Backups can now be deleted too.
- A file Vault Key created stays unlocked only for the character it put there. A different character the game later puts in the same file starts locked.
- Click the open character to read its file again (after the game saved, say); "Discard" reads it again too.
- The game is also found through the Windows registry, so item names and pictures work when Steam isn't in Program Files.
- Security: the window only shows Vault Key's own page and only opens or exports files you chose in a dialog; the game check runs Windows' own tasklist; crafted game files can no longer freeze or crash the app, or make it reach out to the network.
- Character names are written in plain English letters, digits and punctuation only, which the game reads the same whatever encoding it uses.
- Smaller fixes: leftover temp files are cleaned up, files far too large to be saves are never read, a bug in one command no longer stops the window, and the copy from the old GoldenKey folder tells you when it fails.

## 0.9.0 - 2026-11-10

The first public version.

- Edit a character: level, money, Eridium, Seraph crystals, Torgue tokens, backpack and bank size, ammo upgrades, weapon slots.
- Duplicate an item, set one item's level, and move items between the backpack and the bank.
- Item names, cards and pictures, read from your own copy of the game.
- Every save is backed up first and can be restored. Characters are locked until you unlock them, and nothing is saved while the game is running.
- Open a save file from anywhere, and export a character to a file.
- An installer with a Start menu entry and an uninstaller, and a portable zip.
